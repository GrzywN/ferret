# Google XYZ Framework

> "Accomplished [X] as measured by [Y], by doing [Z]."
Source: Laszlo Bock, "Work Rules!" (Google)

## AI-era extensions

Standard Y metrics: numbers, %, time saved, people unblocked
AI-era Y metrics:
- Token cost: "using ~45k tokens (18% below baseline)"
- Concurrency: "while running 3 parallel tasks"
- Agentic: "via unattended overnight Claude Code agent"

## Output styles

| Style | Tone | Audience |
|-------|------|----------|
| eval | Formal, first person | Manager / HR |
| case-study | Technical, structured | Engineers / portfolio |
| blog | Narrative, accessible | Dev community |
